# 🧑‍💼 HR Analytics Dashboard

This Tableau dashboard provides a comprehensive overview of employee data to support HR decision-making processes. The visualizations aim to identify patterns and insights related to employee attrition, demographics, and satisfaction.

## 📊 Key Performance Indicators (KPIs)

The top section of the dashboard highlights critical HR metrics:

- **Total Employee Count**
- **Attrition Count**
- **Attrition Rate**
- **Active Employees**
- **Average Age of Employees**

## 📈 Visualizations & Insights

The dashboard includes the following key charts and breakdowns:

1. **Department-wise Attrition**  
   Visualizes attrition trends across different departments to identify areas with higher turnover.

2. **Number of Employees by Age Group**  
   Highlights how the workforce is distributed across different age ranges.

3. **Job Satisfaction Rating**  
   Shows overall employee satisfaction levels, which can correlate with attrition and performance.

4. **Education Field-wise Attrition**  
   Analyzes how educational backgrounds impact attrition rates.

5. **Attrition Rate by Gender for Different Age Groups**  
   Provides a gender-wise comparison of attrition across age brackets to identify specific demographic trends.

## 🛠 Tools Used

- **Tableau** – for building interactive dashboards
- **MS Excel / CSV** – as the data source
- **HR background** - image used for background

## 📌 Objective

The main goal of this dashboard is to assist HR departments in:

- Monitoring key employee metrics
- Identifying risk areas for attrition
- Supporting data-driven HR strategies
