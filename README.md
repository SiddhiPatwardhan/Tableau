# 📊 Tableau Projects Repository

This repository is a collection of data visualization projects created using **Tableau**, a leading business intelligence and data visualization tool. The aim of this repo is to showcase how raw data can be transformed into clear, interactive, and meaningful dashboards.

## 📌 What is Tableau?

**Tableau** is a powerful and user-friendly data visualization software that enables users to create interactive and shareable dashboards. It connects easily to various data sources and allows deep insights through drag-and-drop analytics — no coding required.

Whether it's analyzing trends, monitoring KPIs, or presenting complex datasets in a simplified form, Tableau helps make data-driven decisions more accessible and impactful.

## 🎯 Repository Purpose

- To maintain a structured portfolio of Tableau dashboards.
- To demonstrate proficiency in visual storytelling and dashboard design.
- To explore and share insights derived from various public or real-world datasets.

## 🛠 Tools & Technologies

- Tableau Public / Tableau Desktop
- Data sources: Excel, CSV, public datasets
- Data cleaning using Excel, or directly within Tableau
