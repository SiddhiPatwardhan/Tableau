# 📊 Netflix Dashboard using Tableau

This project showcases an interactive Tableau dashboard that visualizes and analyzes Netflix’s content catalog, including movies and TV shows. The dashboard helps explore trends in content distribution by country, genre, rating, and release year.

---

## 🔍 Project Overview

The goal of this project is to provide meaningful insights into Netflix’s content library using powerful visualizations. It allows users to:

- Analyze the distribution of content by country
- Compare the number of movies vs. TV shows
- Identify the most popular genres
- Explore content release trends over time
- View key metrics of any selected title

---

## 🎯 KPIs (Key Performance Indicators)

When a specific movie or TV show is selected, the dashboard displays the following KPIs:

- **Title**
- **Rating**
- **Genre**
- **Description**
- **Duration**
- **Date Added**
- **Release Year**

---

## 📈 Visualizations Included

The dashboard contains the following charts:

1. **🌍 Total Movies and TV Shows by Country (Map)**  
   - Visual map showing the number of titles from each country.

2. **⭐ Rating Distribution (Bar Chart)**  
   - Bar chart representing the count of content across different ratings (e.g., TV-MA, PG).

3. **🎬 Content Type Distribution (Movies vs. TV Shows)**  
   - Pie/Donut chart showing the proportion of Movies and TV Shows.

4. **🏆 Top 10 Genres (Horizontal Bar Chart)**  
   - Displays the most frequent genres in Netflix’s catalog.

5. **📅 Total Movies and TV Shows by Year (Area Chart)**  
   - Area chart illustrating the trend of content released over the years.
